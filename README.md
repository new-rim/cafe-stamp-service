## 핵심 아이디어

**기존 스탬프의 모순** — 타겟(커플·20대 여성 모임)은 같은 카페를 다시 가지 않는데, 스탬프는 재방문을 보상한다. 그래서 적립의 단위를 **매장에서 행동으로** 옮긴다.

```
기존   A카페 10번 방문  →  A카페 무료 음료
지금   서로 다른 카페 12곳  →  제휴 카페 어디서나 쓰는 3,000원 쿠폰
```

**정산 구조** — 쿠폰 3,000원은 도장을 찍어준 12곳이 250원씩 나눠 낸다. 청구는 쿠폰이 생기는 순간에만 발생하고, 카페는 도장을 찍는 즉시 고객 알림 발송권·노출 가중·손님 분석을 받는다.

**금액 근거** — 개인카페가 지금 손님 1명에게 쓰는 마케팅비(최대 약 200원)에서 역산했다. 도장 손님 1명당 실부담은 **52원**이다.
